# 宣传片视频介绍接入约定

宣传片是 Skill 的入口介绍，不是生产 QA 的替代品。它可以让别人快速理解 Go! Diggy 的角色、故事节奏和证据化工作流，但必须使用已经真实归档、可播放、状态明确的素材。

## 推荐内容

- 10–30 秒，先展示固定角色/车辆，再展示一个清楚的问题、动作和解决结果；
- 使用真实 Go! Diggy 片段或已经确认可公开的宣传片，不用未归档的生成预览；
- 不新增未经确认的角色外形、Logo、字体或对白；
- 如果视频有对白，提供实际音频对应的字幕/转写；
- 同时准备一张缩略图和一句无夸大说明；
- 在 manifest 或 release note 中写明版本、画幅、时长、音频状态和 QA 状态。

## 推荐文件

```text
demo/
├── go-diggy-promo.mp4       # 经过播放和画面/音频 QA 的宣传片
├── go-diggy-promo.jpg       # 缩略图或首帧，不能用错误比例截图
├── go-diggy-promo.en.srt    # 有英文对白时提供
├── go-diggy-promo.zh-CN.srt # 有中文对白时提供
└── SHA256SUMS.txt           # 发布包校验值
```

当前 Skill 包已接入项目已有的 v05 中文与英文宣传片，文件分别为 `demo/go-diggy-promo-zh.mp4` 与 `demo/go-diggy-promo-en.mp4`；封面位于 `assets/gallery/promo-cover.png`。来源与校验值见 `media-index.json`。两版完成完整音视频解码检查，本次未重新进行完整人工听辨。README 已加入封面链接与两版下载入口。宣传片不代表全部集数均已完成。

## QA 门槛

在公开链接前至少确认：

1. MP4 从头到尾可以播放；
2. 尺寸和画幅与记录一致；
3. 角色、车辆、文字和 Logo 没有变形或误用；
4. 音频没有静音、爆音、明显截断或与画面错位；
5. 字幕（如有）来自实际音频并覆盖完整语音；
6. 缩小后仍能看懂“谁/什么角色 + 发生了什么”；
7. 公开链接、文件名和 manifest 状态一致。
