# Go! Diggy 生产与交付 QA 清单

使用时逐项记录状态和证据，不要只打一个总勾。推荐状态：`verified`、`not_verified`、`blocked`、`not_applicable`。

## A. 规范与资产

- [ ] 已读取当前总规范、对应画幅附录和固定工作流
- [ ] 已读取固定人物参考 README、角色命名索引和对应集数说明
- [ ] manifest 记录了规范文件、角色/车辆素材、Logo 和语言版本
- [ ] 所有出场角色/车辆来自已确认素材
- [ ] 脸、比例、颜色、材质和机械结构没有被改动
- [ ] Rolly 滚筒保持宽而正常
- [ ] 角色基础干净，没有无剧情依据的重泥、油污或 Logo
- [ ] 不确定或待确认的单人稿没有被当作固定参考

## B. 分镜与逐镜提示词

- [ ] 每个镜头有唯一 ID 和独立、可复制的提示词
- [ ] 每个镜头只定义一个主要动作
- [ ] 记录了场景、人物职责、机位、反应/停顿和对白意图
- [ ] 相邻镜头的空间轴、道具状态、物体状态和人物朝向连续
- [ ] 已写明禁止生成文字、字幕、Logo、水印和额外角色/车辆
- [ ] 没有把参考稿或提示词当作实际对白

## C. 外部生成素材归档

- [ ] 用户已经下载真实视频到对应集数的原始镜头目录
- [ ] 文件名包含集数、镜头号、内容短名和版本状态
- [ ] 没有覆盖旧候选
- [ ] MP4 可以完整解码和播放
- [ ] 已记录时长、尺寸、帧率、视频轨和音频轨
- [ ] 已抽查开头、中段动作、反应、结尾和关键接缝帧
- [ ] 已记录角色/车辆变形、物体状态断裂或空间轴问题

## D. 实际音频与字幕

- [ ] 字幕来自最终剪辑的实际音频，而不是脚本/分镜复制
- [ ] 已经人工听辨或用 ASR 得到句级时间
- [ ] 每句字幕覆盖完整语音，不提前出现或过早消失
- [ ] 中文版是英文在上、中文在下；英文版是纯英文
- [ ] 普通字幕与顶部关键词是独立层
- [ ] 关键词来自实际语音或明确同步动作，词级起止正确
- [ ] 关键词没有抢在声音前出现
- [ ] 换镜头、变速或移音频后已重算全部后续区间
- [ ] 未在已经烧录字幕的视频上重复叠加字幕

## E. 画幅、Logo 与画面

- [ ] 横屏输出为 1280×720，竖屏输出为 720×1280
- [ ] 使用了对应画幅附录的字幕 PlayRes、字号、位置、描边和动效
- [ ] Logo 使用了对应语言和画幅的批准透明素材
- [ ] Logo 没有贴到角色本体，片头/片尾/正片出现区间正确
- [ ] 字幕和关键词没有溢出、遮脸或遮挡车辆关键结构
- [ ] 角色脸、机械结构和主要动作在缩小观看时仍可读
- [ ] 封面独立原生构图，没有用视频截图、拉伸或错误比例冒充

## F. 输出与状态

- [ ] clean 母版存在且无内嵌字幕
- [ ] 对应语言平台版存在且可播放
- [ ] 独立中文字幕/英文字幕文件存在且可读取
- [ ] 完整视频已从头到尾播放检查
- [ ] 导出文件路径、版本号和校验值已写入 manifest
- [ ] QA 证据目录或链接已写入 manifest
- [ ] `qa_passed` 只在所有必检项有证据后使用
- [ ] `user_confirmed` 只在用户实际确认后使用
- [ ] 未通过或未定位的内容明确标为 `not_verified`、`blocked` 或 `unlocated`

## 最小证据包

一个可以称为“QA 通过”的单集，至少应能找到：

1. 当前 manifest；
2. 关键镜头抽帧拼图；
3. 角色/车辆或接缝问题的对比图（若发生过修改）；
4. 实际音频转写或听辨记录；
5. 字幕文件和最终视频；
6. 尺寸、音频轨、播放和导出检查记录；
7. 变更说明和当前状态。

缺少其中一项时，可以继续工作，但应准确写成“待补证据”，不要把准备中的候选称为交付。
